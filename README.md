## 🌟 Sobre este Portfolio

Portfolio profesional construido **desde cero con HTML, CSS y JavaScript vanilla**. Sin frameworks, solo código limpio y semántico que demuestra mi transición desde UX/Service Design hacia el desarrollo frontend.

### ✨ Features Destacadas

🌐 **Sistema bilingüe** (ES/EN) con arquitectura i18n basada en keys  
♿ **Accesibilidad WCAG** implementada (semantic HTML, ARIA labels)  
🎨 **Animaciones CSS** personalizadas con Intersection Observer  
🖼️ **Image lightbox** para ampliar screenshots de proyectos  
🎭 **Fondos animados** con figuras geométricas en páginas especiales  
📱 **Mobile-first** responsive design para todos los dispositivos

## 💻 Características Técnicas

**🎨 Design System**
- Variables CSS para colores, espaciado y tipografía
- Componentes reutilizables (buttons, cards, badges, modals)
- Sistema de grid responsive con Flexbox y CSS Grid

**⚡ Performance**
- Lazy loading de imágenes
- CSS modular (base.css, components.css, sections.css)
- JavaScript vanilla sin dependencias externas

**♿ Accesibilidad**
- Semantic HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`)
- ARIA labels en elementos interactivos
- Contraste WCAG AAA en textos principales
- Focus states visibles para navegación por teclado

**🌐 Internacionalización**
- Sistema de traducción con keys en archivo `translations.js`
- Toggle ES/EN con persistencia en localStorage
- Traducción dinámica sin reload de página
